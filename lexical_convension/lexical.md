	LEXICAL CONVENSION IN C

There're eight lexical convension in C

1. physical source (file with .c and .h)

2. Trigraph (eg ??/  \) (eg ??=  #)

3. splicing (eg \)

4. preprocessing (eg #)

5. Tokens (eg  6 classes of tokens)

6. comment (/* */ c++ //)

7. white space (eg int main())

8. chaaracter set (eg ascii, unicode)
